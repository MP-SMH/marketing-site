# StøtMedHjerte Marketing Site - Final Fix Package

This package contains the complete final fix delivery for the marketing homepage.

## Install
Copy the `components/marketing` files and `pages/Home.v8.jsx` into the project, then point the homepage route to `Home.v8.jsx` or rename the files to the project convention after import verification.

## Important
The package keeps the class-based `mkt-*` CSS structure and uses pretty-printed component-scoped CSS.

## Navbar
Navbar behavior is still project-level. It must not render as a white bar over dark sections. See `docs/INTEGRATION-NOTES.md`.
